## ⚔️ Main Quest — DhanDrishti

<table>
<tr>
<td width="60%">

**DhanDrishti** is an Android app that detects Indian Rupee denominations in real time and reads them out for visually impaired users.

- 📱 On-device, real-time camera inference
- 🧠 Computer vision model trained for INR notes
- 🔊 Audio feedback built for accessibility
- 🎯 Goal: fast, reliable, and usable without sight
